# AL Rehman Meta Eggs — React UI Project 🥚🌱

A complete, modern, reactive UI setup of **AL Rehman Meta Eggs** built with **React (Vite) + Tailwind CSS + FontAwesome 6**.

## 🚀 How to Run Locally

### 1. Simple 1-Click:
Directly double click **`start-dev.bat`** in this folder!

### 2. Or using Terminal / VS Code:
```bash
# In the project root (D:\allakermegg):
npm run dev
```

The application will start at:
👉 **http://localhost:5173/**

## 📦 What's Included

- **VIP Celestial Preloader**: Orbital animated preloader with auto-dismiss.
- **Header / Navigation**: Brand logo, smooth scroll navigation, Login & Register CTAs.
- **Hero Section**: 3D orbital stage with 6 balanced rotating satellites, constellation sparkle pips, and central dynamic plan visual.
- **About Section**: 3D interactive showcase, live production badge, 4 Bento cards, trust metrics.
- **Available Plans**: Dynamic plan card with revolving orbit ring, daily yield highlight, and 2x2 specs grid.
- **3D Live Poultry Simulation**:
  - Fully interactive procedural animated hen (walking, laying, celebrating, returning).
  - Animated coop door, rolling egg chute, and 6-slot collection tray.
  - Confetti particle burst upon tray completion.
  - Interactive "Lay Egg Now" button and "1x / 2x Turbo Speed" toggle.
  - Live batch PKR calculations and lifetime egg counters.
- **Farm Calculator**:
  - Dynamic unit slider (1 to 50) and preset multiplier buttons (1x, 5x, 10x, 20x, 50x).
  - Real-time Daily Yield, Daily Cash (PKR), and 30-Day Estimated Profit.
- **How It Works & FAQs**: 3-step guide and interactive toggleable accordion.
- **Footer & Mobile Navigation**: Complete footer and mobile sticky action bar.
